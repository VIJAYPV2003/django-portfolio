# Personal Portfolio Website

A responsive personal portfolio built with Python and Django. Projects and skills are stored as data in the view and rendered with Django template loops, so adding a new project takes one entry in a list instead of editing HTML.

## Features
- Responsive layout that works on desktop and mobile
- Sections: Hero, About, Skills, Projects, Contact
- Data-driven skills and project cards
- Smooth-scrolling navigation

## Tech Stack
Python, Django, HTML, CSS

## Run Locally
1. Clone the repository
```
   git clone https://github.com/VIJAYPV2003/django-portfolio.git
   cd django-portfolio
```
2. Create and activate a virtual environment
```
   python -m venv .venv
   .venv\Scripts\activate
```
3. Install dependencies
```
   pip install -r requirements.txt
```
4. Start the server
```
   python manage.py runserver
```
5. Open http://127.0.0.1:8000/
